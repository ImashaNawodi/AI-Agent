# 🧠 AI Research Assistant (LangChain + OpenAI)

This project is an **AI-powered research assistant** built using **LangChain**, **OpenAI GPT**, and **community tools** like **DuckDuckGo** and **Wikipedia**.  
It can automatically:
- Search the web and Wikipedia for information.
- Summarize research topics.
- Save structured research results into a text file.

---

## 🚀 Features

- 🔍 **Web Search** — Uses DuckDuckGo for real-time information.
- 📚 **Wikipedia Lookup** — Retrieves quick summaries from Wikipedia.
- 🧾 **Structured Output** — Returns results in a Pydantic model format.
- 💾 **Save Function** — Stores research results with timestamps into a `.txt` file.
- 🧠 **LLM-Powered Agent** — Uses GPT (via OpenAI) to decide when and how to use tools.
